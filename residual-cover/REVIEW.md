## Self-review of the new proof

The same authoring assistant reconstructed the proof against the original
coordinate predicates. These checks were performed before packaging:

1. A selector mark is precisely a mandatory right vertex in its prefix.
   The required monotonicity directions are mandatory under adding LEFT
   vertices and deleting OTHER RIGHT vertices. They follow by contraposition
   from the correctly oriented exposure rules, proved by augmenting paths.
2. The selector comparison uses one order on the shared i coordinate.
   Different local orders can fail; an exact failed construction is kept.
3. For fixed s→j, every arrow in F(P_j,I^s) gives an original conflict.
   This proves BOTH missing-right isolation (using original Z) and missing-
   left isolation (using original H plus the supplied cover K_B).
4. The count |Q|=|W\U| is per unchanged j, using the supplied saturation
   matching. The count |D|<=|V| is per unchanged s. All vertices have tags;
   overlapping coordinate names do not identify copies.
5. G+ is applied only with W=R_alpha. Its maximum N auxiliary size is t.
   R_alpha is disjoint from the core T. The inherited core identity adds k
   once, and monotonicity from R_alpha to RT supplies G.
6. The same relation, not the reversed relation, is used in transposition.
   Empty inputs, nonminimum covers, strict W subsets, and negative integer
   expressions require no altered definition or truncated subtraction.

This is self-review, not independent human or separate-agent review.

## Code inspection before execution

The newly written converter, verifier, fixture maker and diagnostic scripts
were inspected for their support predicates, augmenting-path directions,
cover construction, strict type checks, deterministic iteration and absence
of external execution/network operations before their first runs. Later
small changes (a fixed-original-corner fixture, optional seed argument,
and strict CLI JSON loading) were inspected before replay.

The new verifier shares no optimizer or support-building code with the
producer. It separately reconstructs corners via existential conditions.
It requires actual `int`, not `isinstance(int)`, before any coordinate
membership or equality comparison. This covers original pairs, W, order,
alpha, K_B, K_N, selector coordinates, prefix matchings/covers, and extension
paths. The rejection test mutates EVERY integer leaf in two complementary
fixtures, including all relevant certificate/path field families.

The initial 3x3 selector test was a direct exhaustive matching DP. The final
retained diagnostic additionally verifies matching/cover certificates for
every prefix and compares the two implementations. No failed numerical
run was reinterpreted as a proof; all recorded final checks passed.
