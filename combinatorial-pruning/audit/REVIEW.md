Fresh normal/optimized replay reproduced every reported count. A third
audit-owned implementation reconstructs the literal corner predicates and
computes graph optima by minimum-cover subset enumeration. It checks the
small exhaustive inputs, 80 fresh cases and all 512 3-by-3 supports, with
the exact counts in STATUS.md. It also checks original-Z pruning optima
and semantic/path/exposure-list corruption rejections. Standalone -I execution
confirms the fixture checker does not require producer/probe modules.

The audit found a real format gap: Python tuple equality accepted certificate
False/0.0 coordinates as aliases for integer zero. No false graph optimum was
demonstrated, but the representation was too permissive. This public edition
adds one strict tagged-vertex decoder at every certificate entry point and an
exact integer schema check. All original valid fixtures still pass and remain
byte-identical. Twenty-eight targeted corruptions now reject in both modes,
including graph witnesses, deletion witnesses, normalization and extension
paths/records, numeric schema aliases, tags and vertex shape.

The core proof Sections 1–7 are unchanged. Repairs were made in a separate
release copy, not silently applied to the original archive. Fresh run output
is retained under logs/; the complete private audit remains preserved separately.

No human referee or Lean verification is claimed. Lean execution was unavailable
in the bounded local inspection; no toolchain was installed. This does not
turn ordinary proof into formal verification or block an accurately qualified
partial-result release. No full Seymour manuscript endorsement follows.
